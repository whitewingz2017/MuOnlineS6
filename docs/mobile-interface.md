# Mobile interface

Mobile theme uses a compact bottom-center chat log. Drag its top handle upward to enlarge it, drag within the log to scroll, and use the chat button to open the composer. Tapping the message or whisper field opens Android's inline keyboard; the chat moves above the keyboard. Closing the composer dismisses it. Supported channels reuse the existing server chat routing.

Tap the character portrait for character stats. The separate character menu icon and bottom-center resource HUD are removed in Mobile theme. Three configurable potion slots sit above the joystick. Experience spans the bottom edge, with current/next experience and level/progress labels.

The map header toggles a right-side travel dropdown with map names, level requirements and Zen costs. Rows use the existing eligibility checks and travel requests, and the list supports dragging and mouse-wheel scrolling.

Helper opens a touch layout with Hunting, Recovery and Loot tabs, scrolling, learned-skill selection and named-item editing. Changes are kept in a draft until Save; Cancel discards them. It uses the existing Helper configuration and behavior. Desktop themes retain their existing windows.
