# MuMain live rendering checks

Work in progress. No skill is certified as visually identical yet, and the full class comparison is unfinished.

Reference: the built MuMain client, connected to the test server. Stationary monster 971 was created by the user. Native screenshots and cast metadata are under `Publish/SkillComparison/MuMain`; actual TwinMU render fixtures are under `Publish/SkillComparison/TwinMU`. Timeline sheets are under `Publish/SkillComparison/Sheets`.

## Capture limitations

Native timings begin at the input acknowledgement and include casting wind-up. TwinMU frame numbers begin after effect loading and use 25-Hz animation units. Columns are timelines, not proof of equal elapsed effect age. The reference has equipped gear and Fenrir, while the fixture uses naked class models and a player as its target. The camera is source-derived but not calibrated to the live camera. Terrain objects and lighting also differ. Full-frame pixel equality cannot be assessed from these conditions.

The `*-timed` TwinMU fixtures freeze scene updates during effect loading and use the same animation factor for elapsed-time effects and capture numbering. Earlier `*-stable` fixtures can show a short effect after it has already expired and must not be used to conclude that a renderer is missing. Source-controlled production effect code is used by the fixture.
